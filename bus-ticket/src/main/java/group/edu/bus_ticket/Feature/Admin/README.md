# Admin — Quân

Chức năng **Quản trị hệ thống** (mục B) và **Authentication/Authorization chung** (mục A).

| Mã | Chức năng |
|---|---|
| A1–A4 | Đăng nhập, đăng ký, quên mật khẩu, phân quyền |
| B1 | Quản lý tài khoản người dùng |
| B2 | Quản lý tuyến đường |
| B3 | Quản lý xe bus |
| B4 | Quản lý lịch trình / chuyến |
| B5 | Quản lý giá vé & khuyến mãi |
| B6 | Báo cáo & thống kê |

> Thư mục do Quân phụ trách. Đặt endpoint dưới `/api/admin/**` và `/api/auth/**`.
